Хранилище — 2026-11-02: подготовлен раздел настроек для обсуждения через

Экран описывает состав хранилища и конфигурацию по умолчанию; не выдаёт имя
volume по умолчанию за результат Docker inspect. Фактический путь на хосте
пока не считывается. Поле новой папки и «Предпросмотр переноса» показывают
план с указанным путём. Это прототип: ввод живёт только до закрытия настроек,
не сохраняется на сервере и ничего не перемещает. В разделе скрыта общая
кнопка сохранения; сведения о несохранённых правках других разделов остаются.
Sidebar получил внутренний скролл для доступа к пятому разделу в низком окне.

Основа механики — [Docker volumes](https://docs.docker.com/engine/storage/volumes/)
и [Compose external volumes](https://docs.docker.com/reference/compose-file/volumes/).
Рабочий перенос нужно выполнять на хосте после остановки приложения, копируя
весь каталог данных с сохранением исходного хранилища. Docker socket, host
mounts и новые права контейнера не добавлялись; Compose/backend не менялись.
Изменённые исходники прочитаны; тесты, build, lint, typecheck, браузер,
визуальная проверка и команды управления Docker не запускались.

Теги и настройки — 2026-11-02: прямой фидбек Agentation задаёт короткий
разделитель по центру под превью и одну строку из 3–5 тегов. Reference lock —
текущие карточки Kakuoku: сохраняются фон, аватарки, крупные заголовки и текст,
добавлены только линия 44×1px и теги 13px. Длинные теги сокращаются с ellipsis,
полный набор доступен в aria-label, отдельный тег — в title. Пока тегов нет,
карточка показывает «Без тегов»; не подставляем фиктивные назначения.

В меню настроек добавлены «Теги»: редактирование общего набора по строкам.
Поиск по тегам доступен в основной строке поиска. Начальный набор — 36 тем, максимум 64; теги до
24 символов. Использован существующий SL textarea controller с теми же
refresh/destroy и счётчиком; нового SL экспорта нет. Модель
выбирает теги вместе с превью и сводками сортировки, без дополнительного запроса.
Демопримеры имеют заранее заданные теги; произвольные пользовательские заметки
в демке не размечаются моделью. Существующие заметки получают теги при следующем
обновлении AI-превью, без массового платного вызова.

## README cover and interface languages

The README cover uses the existing app as its reference: warm paper, pastel note
cards, charcoal typography, and large illustrated heads. It contains only the
Kakuoku wordmark, so both README languages share one asset. The generated image
is `docs/assets/readme-cover.png`; its prompt and relative references are stored
in `readme-cover.prompt.json`. No personal note content was used.

The root README is English; `README.ru.md` preserves the Russian documentation.
Both link to each other. Settings use the existing native select styling for an
immediate Russian/English choice, remembered only as `kakuoku.language` in the
browser. `src/i18n.mjs` and `src/locales/en.json` translate UI and service messages,
including accessibility labels. User content and saved prompts stay unchanged.
SL UI controllers accept an optional translation callback and refresh labels
without remounting or restarting a pending operation.

This update was reviewed through source reading only. No build, test, browser,
rendered source audit, or production deployment was performed.
